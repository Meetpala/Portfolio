## Setup / Installation
Since this is a static website, no complex setup is required. 
1. Clone the repository: `git clone https://github.com/Meetpala/Portfolio.git`
2. Open `index.html` in any modern web browser.

## Hosting
This project is designed to be easily hosted on **GitHub Pages**. 
To host it yourself:
1. Go to your repository settings on GitHub.
2. Navigate to the **Pages** section.
3. Select the `main` branch as the source and save. 
4. Your site will be live in a few minutes!
